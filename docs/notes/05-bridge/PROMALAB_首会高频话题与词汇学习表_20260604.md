# PROMALAB 首会高频话题与词汇学习表

用途：每天复习 15-20 分钟。目标不是背完所有词，而是开会时听到关键词能立刻判断对方在讨论哪一类问题，并能用简单英语接住。

## 1. 你最可能遇到的会议话题

| 话题 | 对方可能在问什么 | 你要听懂的核心 | 你的安全回应方向 |
|---|---|---|---|
| Company background | Xenta 是什么公司？有没有注册和生产能力？ | 对方在判断供应商是否可靠。 | 简短讲 ISO13485、GMP、CE/FDA/NMPA 基础，不要讲太久。 |
| Current portfolio | 你们有哪些产品平台？ | 对方想知道是否只卖单一产品。 | 四平台带过，今天聚焦 X-Lab mini / LICA。 |
| Product positioning | X-Lab mini 和他们现有产品有什么关系？ | 他们怕你替代已有品牌或冲突。 | 强调 complement, not replace。 |
| Methodology | LICA 和 CLIA、FIA、colloidal gold 有什么不同？ | 对方在判断技术价值。 | 用操作优势解释：room temperature, whole blood, no liquid circuit, low maintenance。 |
| Customer fit | 适合哪些客户？ | 他们在想能卖给谁。 | private labs, emergency, ICU, primary hospitals, low-to-medium volume labs。 |
| Test menu | 有哪些项目？哪些有 CE？ | 对方在判断首批能否落地。 | 不要念完整菜单，反问他们优先方向。 |
| Sample workflow | 全血、血清、血浆怎么做？要不要离心？ | 对方在判断实验室工作量。 | whole blood compatible, no centrifugation for applicable assays, check IFU per assay。 |
| QC and performance | 精密度、CV、质控、校准怎么样？ | 对方在判断是否能进实验室。 | 说 QR code calibration, third-party QC available, performance depends on assay and IFU。 |
| Registration | 摩洛哥注册需要什么资料？ | 对方在判断是否麻烦。 | 说可以后续提供 CE, IFU, technical file summary, FSC if available。 |
| Service and training | 谁负责装机、培训、售后？ | 对方在判断代理商负担。 | 说需要共同确认 service model, training package, application support。 |
| Commercial terms | 价格、MOQ、独家代理、付款方式？ | 对方可能提前切商业。 | 首会先不展开，先确认 fit，再谈 quotation and distributor terms。 |
| Pilot / evaluation | 能不能先试用或 demo？ | 对方想看验证路径。 | 建议 technical review 后再讨论 pilot site and success criteria。 |

## 2. 首会必须熟的 40 个核心词

| English | 中文理解 | 开会里怎么听 |
|---|---|---|
| distributor | 经销商 / 代理商 | 对方说自己渠道能力或合作模式。 |
| portfolio | 产品组合 | 他们问你们有什么产品，或他们已有代理品牌。 |
| product line | 产品线 | 比 portfolio 更具体，例如 immuno line。 |
| positioning | 定位 | X-Lab mini 到底卖给谁、替代谁、补充谁。 |
| complement | 补充 | 最重要词之一：补充现有系统。 |
| replace | 替代 | 谨慎词。最好说 not replace, but complement。 |
| compact immuno | 小型免疫平台 | 你今天要验证 PROMALAB 是否缺这一块。 |
| routine lab | 常规实验室 | PROMALAB 可能较接近这类渠道。 |
| central lab | 中心实验室 | 大型医院或大通量检测场景。 |
| decentralized testing | 分散式检测 | 不完全依赖中心实验室的检测模式。 |
| POCT | 即时检测 | near-patient / point-of-care testing。 |
| CLIA | 化学发光免疫分析 | 大类技术，不一定都是大型仪器。 |
| LICA | 光激化学发光 | X-Lab mini 的核心方法学。 |
| FIA | 荧光免疫层析 | 常见 POCT 技术，通常更简单但性能有限。 |
| colloidal gold | 胶体金 | 快检卡技术，多为定性。 |
| throughput | 通量 | 每小时能做多少测试。 |
| channel | 通道 | X-Lab mini 是 12 independent channels。 |
| random access | 随机上样 | 不用批量凑齐，可以随来随做。 |
| continuous loading | 连续上样 | 检测过程中也可继续加样。 |
| first result | 首个结果时间 | X-Lab mini 资料里常见 3-10 mins。 |
| TAT / turnaround time | 周转时间 | 急诊、ICU、流程痛点高频词。 |
| whole blood | 全血 | 能减少离心和样本处理。 |
| serum | 血清 | 离心后样本。 |
| plasma | 血浆 | 抗凝后离心样本。 |
| centrifugation | 离心 | 如果对方说 sample preparation，大概率和这个有关。 |
| reagent | 试剂 | 他们可能问储存、有效期、包装。 |
| shelf life | 有效期 | 18-24 months 这种表达。 |
| room temperature | 室温 | LICA 的操作优势之一。 |
| cold chain | 冷链 | 大型 CLIA 或部分试剂的痛点。 |
| calibration | 校准 | X-Lab mini 可讲 QR code calibration。 |
| QC / quality control | 质控 | 实验室非常关心。 |
| CV | 变异系数 / 精密度 | 越低表示重复性越好。 |
| sensitivity | 灵敏度 | 检出低浓度能力，别和 specificity 混。 |
| specificity | 特异性 | 排除干扰、减少假阳性的能力。 |
| LoD / limit of detection | 检出限 | 更技术型客户会问。 |
| correlation | 相关性 | 和 Roche/Abbott 等结果对比时会问。 |
| IFU | 使用说明书 | 很多性能和样本类型最终以 IFU 为准。 |
| CE mark | CE 认证 | 对注册和可信度有帮助。 |
| FSC | Free Sale Certificate | 注册资料中可能需要。 |
| technical file | 技术文件 | 注册/评估时可能要。 |
| pilot site | 试点客户 / 试点医院 | 下一步评估落地场景。 |

## 3. 你可能听到的句子和真实含义

| 对方可能说 | 真实含义 | 你可以怎么接 |
|---|---|---|
| What is the difference from traditional CLIA? | 他们要技术差异，不是完整原理课。 | The key difference for users is simpler workflow: no liquid circuit, room-temperature reagent, whole blood compatibility, and compact format. |
| Do you already have CE? | 他们在判断注册可行性。 | Yes, we have CE-marked assays. Availability depends on each assay and local registration. We can share the list after the meeting. |
| Which tests are available now? | 他们想知道首批能卖什么。 | The menu covers cardiac, inflammation, thyroid, fertility, infectious disease and more. Which menu is most relevant for your customers? |
| Do you have troponin? | 他们可能关注心肌急诊。 | Yes, cardiac markers are part of the menu. We should confirm the exact assay status and local registration need. |
| What about QC? | 他们担心实验室认可和日常质控。 | QC is important for routine use. We can discuss third-party QC, internal QC process, and IFU requirements in the technical review. |
| Is it open system or closed system? | 他们想知道试剂是否必须用原厂。 | It is designed as an integrated analyzer and reagent system. We can clarify the exact operating model in technical review. |
| What is the price? | 他们想进入商业条件。 | We can discuss price after confirming fit, first menu, expected volume, and support model. Today I suggest we first confirm the technical and portfolio fit. |
| Can we get exclusivity? | 他们想锁市场。 | Exclusivity normally depends on market plan, registration responsibility, first order, and performance commitment. Too early for today. |
| Who handles installation and service? | 他们在算代理商负担。 | We can provide training and support, but the local service model should be defined together with Promalab. |
| Do you have references? | 他们想降低风险。 | We can share available reference information and documents after understanding which application scenario matters most. |

## 4. 重要话术：短句就够用

### 开场

Today is more of an exploratory technical discussion, not a quotation meeting.

We would like to understand whether compact immuno has a real fit in Promalab's current portfolio.

### 定位

We do not see X-Lab mini as a replacement for large CLIA systems.

The positioning is to complement existing workflows, especially in decentralized or low-to-medium volume settings.

### 技术

LICA combines POCT-style simplicity with chemiluminescence-level quantitative performance.

The user-side advantages are whole blood compatibility, room-temperature reagents, no liquid circuit, and low maintenance.

### 反问

Which customer type would be most relevant for Promalab?

Which menu would be the first priority in Morocco?

Where do your customers still feel workflow pain today?

### 收口

If there is no fit, that is also useful for both sides.

If there is fit, the next step should be a focused technical review, not a price discussion immediately.

## 6. 每天 20 分钟学习法

1. 第 1-5 分钟：读 10 个词，只读英文和中文，不背解释。
2. 第 6-10 分钟：选 3 个词造句，例如 `TAT`, `whole blood`, `QC`。
3. 第 11-15 分钟：练 3 个反问句，让自己习惯把问题抛回客户。
4. 第 16-20 分钟：复盘一个场景，例如“客户问价格怎么办”“客户问菜单怎么办”。
