每周怎样用

  1. 选一个主题，先独立尝试定义题、证明题和反例。
  2. 卡住时定位最小缺口，再查资料或提示。
  3. 记录独立完成、提示后完成、只读懂解答三种状态。
  4. 隔几天闭卷重做，并寻找一个论文或计算应用。

读论文的检查问题

  • 作者研究什么对象，优化什么目标？
  • 结论用到了哪些假设？
  • 我无法解释的最小步骤是什么？
  • 能否在低维或线性情形重建？
  • 证明与实验分别支持多大的主张？
