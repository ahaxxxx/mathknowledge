# 英语语法与学术阅读

这一部分把英语能力整理成一套可以反复翻看的静态知识库。目标不是背语法规则，也不是刷听力题，而是逐步形成接近美籍大学生到 PhD 阶段所需要的英文处理能力：看见复杂句能拆结构，听到学术表达能抓逻辑，遇到陌生词能判断词性、意义范围和论证功能。

## 总体定位

英语能力分成两条互相支撑的主线：

1. [语法与阅读](./01_grammar_reading/README.md)：从词汇形态、句子骨架、修饰系统、压缩系统、逻辑系统和学术语体进入高密度英文阅读。
2. [学术听力](./02_academic_listening/README.md)：从声音输入、语言解码、学术理解和分级材料库进入大学课堂、论文讲解、seminar 与 Q&A。

## 使用原则

这不是日更栏目，也不是任务打卡系统。内容会尽量固定、清晰、可复读。每次回看时，只要多看懂一层结构、多听出一个逻辑信号、多认出一个学术表达，这个系统就在发挥作用。

## 第一阶段先做什么

第一阶段不追求百科全书式完整，而是先建立“经常翻就会进步”的核心骨架：

- 语法阅读：先掌握句子骨架、修饰系统、非谓语、名词化、逻辑连接和学术语体。
- 词汇形态：把词根词缀作为阅读中的判断工具，而不是孤立背诵表。
- 学术听力：先用一组静态精选音频，从 B2 到 PhD 分层适应语速、结构和学术表达。
