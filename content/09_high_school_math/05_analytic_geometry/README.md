# 解析几何与圆锥曲线

解析几何的本质是：用坐标和方程研究几何图形。点变成坐标，线和曲线变成方程，位置关系变成代数运算，几何结论变成可验证的等式、不等式和恒等关系。

如果目标是高考数学 130 到 140 分，解析几何不能只停留在“会背椭圆双曲线抛物线公式”。真正要练的是：会设点、会设直线、会联立、会用韦达、会表达目标、会消参数、会判断最值和范围。

## 课堂推进建议

1. 第一讲：坐标、斜率、直线方程、点到直线距离。
2. 第二讲：圆的方程、直线与圆、切线与弦长。
3. 第三讲：圆锥曲线统一定义，建立“轨迹 = 点的集合”意识。
4. 第四讲：椭圆，重点是定义、焦点、离心率和标准方程。
5. 第五讲：双曲线和抛物线，用对比法降低记忆负担。
6. 第六讲：直线与圆锥曲线联立、判别式、韦达和弦长。
7. 第七讲：定点、定值、定直线。
8. 第八讲：最值与范围、综合大题策略。

## 高分训练原则

每道解析几何题至少问六件事：

1. 当前图形是什么：直线、圆、椭圆、双曲线、抛物线，还是组合问题？
2. 目标是什么：求方程、求交点、求弦长、求面积、求参数、证明定值，还是求最值？
3. 点怎么设：直接设坐标，还是利用曲线参数、韦达关系、中点关系？
4. 直线怎么设：斜率式、点斜式、截距式、参数式，还是避免斜率不存在用一般式？
5. 联立后要保留什么：判别式、根和、根积、弦长、面积、斜率乘积？
6. 最后是否需要检验范围、退化情况和斜率不存在的情况？

解析几何高分不靠“灵感”，靠稳定流程。流程越稳定，计算越不容易散。
