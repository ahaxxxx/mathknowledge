# 立体几何与空间向量

立体几何不是“凭感觉看图”，也不是一上来就硬建坐标系。它研究的是：怎样把空间中的点、线、面、角、距离、体积和球，先用图形关系看清楚，再用向量或坐标稳定计算。

本专题接在平面向量之后最自然：平面向量负责把平面里的方向、夹角、垂直和距离代数化；空间向量进一步把这些工具推广到三维。课堂上要坚持“题干图先自动呈现，解析中的辅助线和坐标系再展开”，避免学生只背步骤而不看图。

3. 第三讲：体积、表面积、等体积法。
4. 第四讲：空间角的几何法。
5. 第五讲：空间向量建系、法向量、线面角和二面角。
6. 第六讲：点线距、点面距、外接球模型。

## 讲题原则

每道立体几何题至少问五件事：

1. 题干图形是什么模型：棱柱、棱锥、正方体、折叠、球，还是组合体？
2. 当前目标是证明平行、证明垂直、求角、求距离、求体积，还是求外接球？
3. 如果用几何法，关键辅助线在哪里？
4. 如果用向量法，坐标原点、基向量和法向量怎么选？
5. 题目中的图形条件有没有被完整使用，例如中点、垂直、面面垂直、正方形、等边三角形？
