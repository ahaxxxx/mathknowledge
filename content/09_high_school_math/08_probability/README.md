# 高中概率：从随机事件到分布与期望

概率研究不确定结果的规律。先说清一次试验是什么，再定义事件或随机变量，最后选择计算方法。本专题承接排列组合，覆盖事件、古典概型、条件概率、独立性、全概率、离散随机变量、期望方差、二项分布、超几何分布与正态分布；逆向条件概率作为拓展。

## 按顺序学习

1. [事件与古典概型](./01_events_classical_zh.md)：样本空间、事件关系、概率与频率、等可能计数。
2. [条件概率与独立性](./02_conditional_independence_zh.md)：乘法公式、放回与不放回、全概率与逆向条件。
3. [离散随机变量](./03_random_variables_zh.md)：分布列、期望、方差与收益比较。
4. [常见分布](./04_distributions_zh.md)：两点分布、二项分布、超几何分布、正态分布及模型边界。
5. [分层训练与完整解析](./05_exercises_zh.md)：10 道基础、进阶与综合题。

## 每次解题的五步

1. 定义事件或随机变量，写清取值。
2. 确认等可能、独立、放回等条件。
3. 选择计数、分支相乘、分类相加或分布模型。
4. 写出推导，而不只列公式。
5. 检查概率范围、分布列总和、期望范围和方差非负。

任选一道抽球题，说清楚“样本点为什么等可能”“分母为什么这样取”“改成放回后哪一步改变”。再用一个反例解释为什么互斥不等于独立。
