# 第五课：正态曲线下面积表示什么

[返回路线](./09_two_week_plan_zh.md)。周五一小时，本地对应考点 38。

## 对象与计算依据

正态分布（normal distribution）描述连续测量值。$X\sim N(\mu,\sigma^2)$ 中第二参数是方差，$\sigma>0$ 为标准差；密度曲线高度不是概率，区间下面积才是概率，单点概率为零。

<figure><img src="../../../assets/probability-course/normal-interval.svg" alt="正态密度曲线关于均值对称，均值到均值加一个标准差的区间被阴影标出，区间概率由面积表示。"><figcaption>示意：阴影是区间面积，曲线高度是密度。</figcaption></figure>

密度关于均值对称，因此等距左右面积相等。标准化 $Z=(X-\mu)/\sigma$ 把区间端点同样变换。常用中心 1、2、3 个标准差内概率约为 0.6827、0.9545、0.9973；这些是正态模型的数值结果，不是一般分布定律。完整定义见[分布讲义](./04_distributions_zh.md)。

:::solution 教师备课与退出检查
复盘放回与不放回；新知先用图解释一个标准差左右面积，再做 X 服从 N(100,225) 的右尾计算。应用阶段让她独立完成作业 2、3，优先发现把 225 当标准差的错误。退出题：标准正态在 0 点密度为正，为什么恰好等于 0 的概率仍是零？高度不是面积。
:::

## 四道核心作业

### 作业 1：密度与概率【自编·辨析】
某连续变量在 x=0 的密度为 0.4。有人据此说 P(X=0)=0.4。指出错误；正态变量的区间开闭端点会影响概率吗？
:::solution 一级提示
区分曲线高度与区间面积。
:::
:::solution 完整解析
密度为每单位区间概率的局部刻画，不能直接当点概率。连续密度模型中单点面积为零，故 P(X=0)=0。正态分布的任何单点概率为零，增加或删去有限端点不改变区间概率。
:::

### 作业 2：标准差与右尾【考点 38 模型改编】
X 服从 N(100,225)，给定中心一个标准差内概率约 0.6827，求 P(X>115)。
:::solution 一级提示
先开方取得标准差，再看 115 离均值几个标准差。
:::
:::solution 完整解析
标准差为 15，115=100+15。中心区间 (85,115) 之外概率为 0.3173，两尾对称，所以右尾概率约 0.15865。若误用 225，区间判断就已错误。
:::

### 作业 3：区间差与数量估计【考点 38 模型改编】
质量指标 X 服从 N(50,4)，中心一、两个标准差内概率为 0.6827、0.9545，求 P(52<X<54)。10000 件同分布产品中，此区间件数的期望约为多少？是否必须独立？
:::solution 一级提示
标准差为 2，目标是右侧一到两个标准差之间。
:::
:::solution 完整解析
两侧环带总面积 $0.9545-0.6827=0.2718$，右半为 0.1359。件数是各产品落入区间的指示变量之和，期望约 1359，期望线性性无需独立。实际件数不必为 1359；独立性会影响波动计算。
:::

### 作业 4：三角函数回访【自编】
求 $y=\sin(2x-\pi/3)$ 的全部单调递增区间及图像对称中心，说明内层变量到 x 的转换。
:::solution 一级提示
令 t=2x-π/3，分别使用正弦的递增区间和零点中心。
:::
:::solution 完整解析
正弦在 $[-\pi/2+2k\pi,\pi/2+2k\pi]$ 递增，内层系数 2 为正，解不等式得 $[-\pi/12+k\pi,5\pi/12+k\pi]$，k 为整数。对称中心满足 $2x-\pi/3=k\pi$，故为 $(\pi/6+k\pi/2,0)$。不能把内层变量的区间端点直接当作 x 的端点。
:::
