足够用于系统补练，并深入许多研究专题。覆盖范围和练习反馈比书单长度更重要。Axler 未覆盖的多项式内容可用 Judson 补充；没有完整官方解答的资料，需要通过讨论、严谨核对与独立重做获得反馈。

## 01 基础训练

- [数学分析：从定义到证明](analysis.md)：英文 / 免费全文 / 章节习题。沿实数、极限、连续与微积分重建分析框架，逐步进入多元分析。
- [高等代数：理解线性结构](algebra.md)：中文可读 / 免费全文 / 证明训练。从向量空间、基与维数，到线性映射、谱定理和奇异值分解。
- [概率论：练习选择工具](probability.md)：英文 / 官方解答 / 视频。从条件概率到条件期望；先做专题题，再在综合作业中自己判断方法。
- [线性代数：计算与几何直觉](strang.md)：英文 / 视频 / 作业解答。为线性方程组、正交投影、最小二乘与特征值补充计算训练。
- [代数补充：群、环与多项式](judson.md)：英文 / 开放教材 / 按需补充。补充线代教材之外的代数内容；从环与多项式连接已有的群、环、域知识。

## 02 连接 AI 工具

- [优化：从目标到算法](optimization.md)：英文 / 免费全文 / 附加习题。建立凸集、凸函数、对偶和最优性条件的框架，把模型转化为可分析的问题。
- [数值方法：误差与稳定性](numerical.md)：英文 / 研究生课程 / 作业解答。理解为什么正确的数学表达式，在计算机上仍可能产生不可靠的结果。
- [统计推断：从样本到结论](statistics.md)：英文 / 视频 / 作业。理解估计、推断与统计方法背后的理论，连接概率知识与数据分析。
- [应用桥梁：最小二乘与建模](vmls.md)：英文 / 免费全文 / 计算实践。把向量与矩阵知识用于拟合、建模和计算，适合从理论进入实验时查阅。
- [统计学习：让推导接受数据检验](isl.md)：英文 / 免费全文 / Python。围绕回归、分类与模型评估，把数学分析连接到可重复的实验。
- [深度学习：串联数学工具](deep.md)：英文 / 免费网页版 / 基础参考。把线代、概率、数值计算和优化放回神经网络的研究语境。

## 03 沿研究问题深入

- [高维概率与学习理论](hdp.md)：英文 / 研究专题 / 习题。从集中不等式、随机矩阵到泛化分析，进入理论研究常用的证明工具。
- [扩散与 Flow Matching](diffusion.md)：英文 / 讲义与实验 / 生成模型。把微分方程、概率和采样联系起来，理解连续时间生成模型。
- [强化学习：决策与反馈](rl.md)：英文 / 视频与课件 / 考试答案。围绕 MDP、动态规划、价值函数与策略梯度建立强化学习的数学框架。
- [几何学习：对称性与等变性](geometry.md)：英文 / 开放章节 / 几何与群。把群作用、不变性与等变性连接到图、网格和几何上的神经网络。
- [信息论与统计的连接](information.md)：英文 / 专题框架 / 教程入口。围绕熵、KL 散度、互信息和统计推断，建立信息论的研究入口。

## 每周怎样用

1. 选一个主题，先独立尝试定义题、证明题和反例。
2. 卡住时定位最小缺口，再查资料或提示。
3. 记录独立完成、提示后完成、只读懂解答三种状态。
4. 隔几天闭卷重做，并寻找一个论文或计算应用。

## 读论文的检查问题

- 作者研究什么对象，优化什么目标？
- 结论用到了哪些假设？
- 我无法解释的最小步骤是什么？
- 能否在低维或线性情形重建？
- 证明与实验分别支持多大的主张？
