# 应用桥梁：最小二乘与建模

把向量与矩阵知识用于拟合、建模和计算，适合从理论进入实验时查阅。

## 资料与官方入口

Introduction to Applied Linear Algebra；Stephen Boyd & Lieven Vandenberghe。

英文 / 免费全文 / 计算实践

- [教材与 Python 配套入口](https://web.stanford.edu/~boyd/vmls/)

## 开始前需要什么

基础线代；使用配套实践材料时需要编程。

## 建议阅读顺序

1. 向量、范数与线性关系。

2. 矩阵、正交性与最小二乘。

3. 带约束和非线性最小二乘等应用。

## 独立训练建议

以下为本站建议的训练任务，不是教材原题或官方作业要求。

1. 从数据问题写出设计矩阵和目标。

2. 比较不同特征与正则化选择。

3. 核对计算残差与理论性质。
