# 统计学习：让推导接受数据检验

围绕回归、分类与模型评估，把数学分析连接到可重复的实验。

## 资料与官方入口

An Introduction to Statistical Learning；Gareth James 等 · Python 版可用。

英文 / 免费全文 / Python

- [官方书籍 / Python 版](https://www.statlearning.com/)

## 开始前需要什么

基础概率统计、线代与 Python。

## 建议阅读顺序

1. 统计学习与模型评估。

2. 回归、分类、重采样。

3. 正则化、非线性方法及后续主题。

## 独立训练建议

以下为本站建议的训练任务，不是教材原题或官方作业要求。

1. 完成一个配套实验，独立解释评价指标。

2. 划分训练与测试数据，排查数据泄漏。

3. 更改模型假设，记录误差变化。
